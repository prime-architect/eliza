# /prepare-pr Workflow

1. Verify current branch is a feature branch and diff is cleanly rebased on `develop`.
2. Confirm owning-package checks pass and gate results are documented.
3. Draft a structured PR title and body referencing resolved tasks.
4. Prepare contribution provenance and verification evidence footer.
5. **DO NOT** push to remotes or create the pull request without explicit user authorization.
