# /plan-feature Workflow

1. Execute `feature-planning` skill.
2. Outline package ownership, core-vs-plugin boundary, and API/schema effects.
3. Identify required test coverage and visual audit needs.
4. Define acceptance criteria and explicitly excluded work.
5. Present the plan to the user and await approval before modifying code.
